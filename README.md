# Super Mario Land - Level Select

A small quality-of-life ROM hack for **Super Mario Land** on Nintendo Game Boy.

This patch permanently enables the game's built-in level select from the title screen.

Normally, level select is only unlocked after completing the game twice: once normally and once in Expert Mode. This hack makes it available immediately while retaining normal difficulty.

## Controls

On the title screen:

- **A** — Cycle through the 12 stages
- **START** — Begin the selected stage

## Patching

Apply either the `.bps` or `.ips` patch to a clean copy of:

**Super Mario Land (World)**

BPS is recommended.

Do not apply both patches.

https://www.romhacking.net/patch/
